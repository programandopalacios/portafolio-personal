## Diseño
La propuesta visual fue desarrollada con un enfoque moderno y profesional, utilizando una paleta oscura con acentos de color para destacar elementos importantes.
La propuesta visual fue desarrollada con un enfoque minimalista, moderno y profesional.  
Se utilizó una paleta cromática equilibrada basada en fondos oscuros profundos con contrastes precisos y acentos luminosos para resaltar elementos clave.  
El sistema tipográfico se apoya en la fuente Inter, garantizando una excelente legibilidad en diferentes resoluciones y tamaños de texto.  
Se cuidó especialmente el espaciado, la jerarquía visual de la información y la coherencia en componentes interactivos (botones, tarjetas, badges de tecnologías y modales).
Se buscó mantener una estética limpia y directa, con una tipografía legible y una estructura que permita al visitante encontrar la información de forma clara y sin distracciones.
Uno de los puntos principales durante el desarrollo fue mantener coherencia visual entre secciones, asegurando que cada bloque de contenido tuviera su propia identidad dentro del conjunto.
