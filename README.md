El proyecto fue realizado con el objetivo de crear una presencia digital profesional, mostrando información personal, habilidades técnicas, proyectos desarrollados y medios de contacto.

## Descripción del proyecto

Este portafolio es un sitio web personal desarrollado para presentar mi perfil como Desarrollador de Software.

El proyecto busca representar mi identidad como desarrollador, mostrar las tecnologías con las que trabajo, los proyectos que he construido y facilitar el contacto con personas o empresas interesadas en colaborar.

La propuesta visual busca mantener una identidad moderna, limpia y profesional, evitando una estructura genérica. Se trabajó con un diseño oscuro, tipografía clara y una experiencia de navegación sencilla.

El sitio fue desarrollado pensando en una correcta visualización desde diferentes dispositivos, con soporte para modo claro y modo oscuro.

---

## Objetivos

Los principales objetivos del proyecto fueron:

- Crear una presencia digital profesional como Desarrollador de Software.
- Presentar mi perfil, formación y áreas de enfoque.
- Mostrar mis habilidades y stack tecnológico.
- Exhibir los proyectos desarrollados con sus tecnologías y enlaces.
- Facilitar el contacto a través de un formulario y canales directos.
- Ofrecer una experiencia adaptable a dispositivos móviles y de escritorio.
- Implementar soporte para modo claro y oscuro.

## Diseño

La propuesta visual fue desarrollada con un enfoque moderno y profesional, utilizando una paleta oscura con acentos de color para destacar elementos importantes.

Se buscó mantener una estética limpia y directa, con una tipografía legible y una estructura que permita al visitante encontrar la información de forma clara y sin distracciones.

Uno de los puntos principales durante el desarrollo fue mantener coherencia visual entre secciones, asegurando que cada bloque de contenido tuviera su propia identidad dentro del conjunto.

## Instalación

Para visualizar el proyecto de manera local, primero se debe clonar el repositorio:

```bash
git clone https://github.com/programandopalacios/portafolio-personal.git
```

Ingresar al directorio:

```bash
cd portafolio-personal
```

Abrir el archivo `index.html` directamente en el navegador. No requiere instalación de dependencias ya que es un proyecto estático.
