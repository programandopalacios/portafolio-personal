Descripción del proyecto

Este sitio web es mi portafolio profesional como Desarrollador de Software y Tecnólogo en Análisis y Desarrollo de Software.
Para este proyecto desarrollé una plataforma web moderna, interactiva y de alto impacto visual, diseñada para exhibir de manera clara y estructurada mis competencias, experiencia técnica y proyectos reales.
La propuesta visual combina una estética sobria y profesional con soporte completo para modo oscuro y modo claro, acabados refinados, tipografía legible y microinteracciones fluidas, evitando estructuras genéricas o sobrecargadas.
El sitio fue desarrollado pensando en una navegación intuitiva, tiempos de carga optimizados, diseño 100% responsivo y total accesibilidad desde cualquier dispositivo.

Objetivos

Los principales objetivos del proyecto fueron:

Crear una presencia digital sólida y profesional como Desarrollador de Software.
Presentar mi perfil profesional, formación académica y filosofía de trabajo.
Exhibir mi stack tecnológico mediante un panel interactivo con filtros por categoría.
Presentar los proyectos destacados con capturas reales, resumen descriptivo, tecnologías utilizadas y enlaces directos a producción.
Facilitar la comunicación directa mediante formulario funcional integrado y acceso rápido a WhatsApp.
Implementar soporte nativo para alternancia entre modo claro y modo oscuro (Dark/Light Mode).
Diseñar una experiencia totalmente adaptable y optimizada para dispositivos móviles, tablets y computadores de escritorio.

Desarrollo

Durante el desarrollo del proyecto se trabajó principalmente en:

Maquetación y estructuración semántica del contenido en HTML5.
Construcción de un sistema de diseño propio mediante CSS puro y variables personalizadas.
Implementación del sistema de cambio de tema (Dark Mode y Light Mode) con persistencia en LocalStorage.
Desarrollo de la lógica de filtrado dinámico para la sección de habilidades técnicas.
Integración y validación del formulario de contacto funcional con Web3Forms.
Optimización de imágenes y recursos multimedia para carga rápida y alto rendimiento.
Adaptación responsiva cuidada para pantallas táctiles, dispositivos móviles y pantallas de alta resolución.
Implementación de animaciones sutiles, microinteracciones y efectos hover para enriquecer la experiencia de usuario.
Diseño

La propuesta visual fue desarrollada con un enfoque minimalista, moderno y profesional.
Se utilizó una paleta cromática equilibrada basada en fondos oscuros profundos con contrastes precisos y acentos luminosos para resaltar elementos clave.
El sistema tipográfico se apoya en la fuente Inter, garantizando una excelente legibilidad en diferentes resoluciones y tamaños de texto.
Se cuidó especialmente el espaciado, la jerarquía visual de la información y la coherencia en componentes interactivos (botones, tarjetas, badges de tecnologías y modales).

Responsive Design

El sitio fue desarrollado para adaptarse fluidamente a diferentes tamaños de pantalla y densidades de píxeles.
Se realizaron ajustes específicos para:

Computadores de escritorio de alta resolución.
Computadores portátiles.
Tablets en orientación vertical y horizontal.
Dispositivos móviles (smartphones de distintas gamas).

Se optimizaron menús de navegación móvil desplegables, distribución de cuadrículas (CSS Grid responsive), tamaños tipográficos escalables y áreas de pulsación táctil cómodas.

Instalación

Para ejecutar el proyecto de manera local, primero se debe clonar el repositorio:

bash
git clone https://github.com/programandopalacios/portafolio-personal.git

Ingresar al directorio:

bash
cd portafolio-personal

Al ser un proyecto estático desarrollado con HTML5, CSS3 y JavaScript Vanilla, no requiere instalación de dependencias con npm. Puede ejecutarse directamente:

Abriendo el archivo index.html en cualquier navegador web.
O ejecutándolo con una extensión de servidor local como Live Server en Visual Studio Code.
